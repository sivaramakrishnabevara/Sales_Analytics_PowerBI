# 📊 Sales Analytics Dashboard using Power BI & MySQL

## 📌 Project Overview

This project presents an **interactive Sales Analytics Dashboard** developed using **Microsoft Power BI** with **MySQL** as the database, managed through **DBeaver**.

The sales dataset was imported into MySQL using DBeaver and connected to Power BI to create an interactive dashboard. The dashboard helps analyze sales performance, profit, customer behavior, and regional performance through dynamic visualizations and KPIs.

---

## 🎯 Objectives

* Analyze sales performance
* Monitor total sales and profit
* Identify top-performing regions and products

## ▶️ How to Use

1. Download the repository.
2. Open `Sales_Analytics_Dashboard.pbix` in Power BI Desktop.
3. If required, reconnect the data source to your local MySQL database.
4. Refresh the data.
5. Explore the dashboard using slicers and filters.
